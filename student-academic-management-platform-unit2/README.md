# Enterprise Student Record and Academic Management Platform — Unit 2

## Agile Mini-Project

This repository contains the complete Unit-2 Agile planning documentation for the **Student Record and Academic Management Platform**.

Unit 2 translates the Unit-1 product discovery work into Agile deliverables: product vision, Scrum roles, epics, user stories, acceptance criteria, product backlog, story-point estimation, sprint planning, Scrum board, burndown chart, Scrum ceremonies, Agile framework comparison, and release roadmap.

## Product

A secure, user-friendly web platform for managing:

- Student records
- Course registration
- Attendance
- Academic performance
- Authentication and security
- Notifications
- Academic reporting

## Recommended Framework

**Scrum** is recommended for this project because the platform has multiple functional modules, evolving requirements, clear stakeholder roles, and a need for incremental delivery through time-boxed sprints.

## Suggested Development Stack

- Frontend: React
- Backend: Node.js + Express
- Database: PostgreSQL
- API: REST
- Authentication: JWT + Role-Based Access Control
- Version Control: Git/GitHub
