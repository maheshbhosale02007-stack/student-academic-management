# Scrum Ceremony Simulation

## Sprint Planning

### Activities
- Review Product Backlog.
- Select stories.
- Estimate effort.
- Define Sprint Goal.
- Identify dependencies.

## Daily Scrum

Each member answers:

1. What did I complete yesterday?
2. What will I do today?
3. What challenges or blockers am I facing?

## Sprint Review

- Demonstrate completed features.
- Inspect the increment.
- Gather stakeholder feedback.
- Update future backlog priorities.

## Sprint Retrospective

Discuss:

- What went well?
- What challenges occurred?
- What should change?
- What actions will improve the next sprint?

## Example Daily Scrum

**Member A:** Completed login UI; today I will integrate validation; blocker: waiting for API contract.

**Member B:** Completed database schema draft; today I will implement authentication persistence; no blocker.

**Member C:** Completed test cases; today I will execute login tests; blocker: test environment setup.
