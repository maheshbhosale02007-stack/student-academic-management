# User Story Repository

## Epic 1 — Student Management

### US-01 Add Student
As an academic administrator, I want to add a student so that the institution can maintain a centralized student record.

### US-02 Search Student
As an academic administrator, I want to search for a student so that I can quickly locate a record.

### US-03 Update Student
As an academic administrator, I want to update student information so that records remain current.

### US-04 Delete Student
As an authorized administrator, I want to delete or deactivate a student record so that obsolete records can be handled appropriately.

## Epic 2 — Course Management

### US-05 Add Course
As an administrator, I want to add a course so that it can be offered to students.

### US-06 Update Course
As an administrator, I want to update course details so that academic information remains accurate.

### US-07 Assign Students
As an administrator, I want to assign students to courses so that enrollments are maintained.

### US-08 View Course
As a student or faculty member, I want to view relevant course details so that I understand my academic schedule.

## Epic 3 — Attendance Management

### US-09 Record Attendance
As a faculty member, I want to record student attendance so that attendance records remain accurate and updated.

### US-10 View Attendance
As a student, I want to view my attendance so that I can monitor my academic status.

### US-11 Attendance Report
As an authorized user, I want to generate attendance reports so that attendance can be reviewed.

## Epic 4 — Marks and Academic Performance

### US-12 Enter Marks
As authorized faculty, I want to enter marks so that student academic performance is recorded.

### US-13 Update Marks
As authorized faculty, I want to update marks before finalization so that corrections can be made.

### US-14 Calculate Grades
As the system, I want to calculate grades using configured rules so that grading is consistent.

### US-15 Result Sheet
As examination staff, I want to generate result sheets so that verified academic results can be reported.

## Epic 5 — Authentication and Security

### US-16 User Login
As a registered user, I want to log in so that I can securely access authorized features.

### US-17 Logout
As a user, I want to log out so that my account is protected after use.

### US-18 Password Reset
As a user, I want to reset my password so that I can regain access if I forget it.

### US-19 Role-Based Access
As an administrator, I want users to have role-based permissions so that sensitive functions are restricted.

## Epic 6 — Notifications

### US-20 Attendance Alert
As a student, I want to receive attendance alerts so that I can take action when attendance is low.

### US-21 Examination Notification
As a student, I want examination notifications so that I know important examination information.

### US-22 Result Notification
As a student, I want result notifications so that I know when results are available.

## Epic 7 — Reporting

### US-23 Student Report
As an administrator, I want to generate student reports so that academic records can be reviewed.

### US-24 Attendance Report
As faculty, I want attendance reports so that class attendance can be analyzed.

### US-25 Performance Report
As an authorized user, I want performance reports so that academic outcomes can be reviewed.

### US-26 Course Report
As an administrator, I want course reports so that course-level information can be analyzed.
