# Scrum Board

## Current Example Board

| Backlog | To Do | In Progress | Testing | Completed |
|---|---|---|---|---|
| Course Report | Add Student | Search Student | Authentication tests | Repository Setup |
| Attendance Alert | Record Attendance |  |  | Project Structure |
| Performance Report | Notifications |  |  |  |

## Workflow

```text
Backlog → To Do → In Progress → Testing → Completed
```

## Board Rules

- A story enters To Do only when sufficiently refined.
- In Progress should contain actively worked items.
- Testing contains completed implementation awaiting verification.
- Completed means the Definition of Done is satisfied.
