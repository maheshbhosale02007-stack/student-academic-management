# Minimum Viable Product (MVP) Definition

## MVP Goal

Deliver the smallest useful release that demonstrates centralized academic record management.

## MVP Features

| Feature | Description | Priority |
|---|---|---|
| Authentication | Secure login and role access | Must |
| Student Registration | Create and maintain student profiles | Must |
| Record Management | Search and update authorized academic records | Must |
| Course Registration | Associate students with courses | Must |
| Attendance | Record and calculate attendance | Must |
| Academic Reports | Generate student academic reports | Must |
| Audit Log | Track critical changes | Should |

## User Stories

### Student

- As a student, I want to log in so that I can securely access my records.
- As a student, I want to view attendance so that I can monitor my academic status.
- As a student, I want to view published results so that I can understand my performance.
- As a student, I want to access an academic report so that I can use it when required.

### Faculty

- As faculty, I want to see my assigned courses so that I can manage classes.
- As faculty, I want to record attendance so that attendance is maintained digitally.
- As faculty, I want to review submitted attendance so that errors can be identified.

### Administrator

- As an administrator, I want to register students so that records are centralized.
- As an administrator, I want to update academic records so that information remains current.
- As an administrator, I want to generate reports so that administrative work is reduced.

## MVP Exclusions

Payments, hostel, library, transport, parent portal, predictive analytics, and native mobile apps.
