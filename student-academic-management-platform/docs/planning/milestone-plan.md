# Milestone Plan

| Milestone | Activities | Output |
|---|---|---|
| M1 | Business understanding | Process/problem notes |
| M2 | Stakeholder research | Stakeholder matrix |
| M3 | Personas | Student/faculty/admin personas |
| M4 | Requirements | FRS + NFRS |
| M5 | Design Thinking | Problem statement + ideas |
| M6 | IBM Design Thinking | Principles + loop |
| M7 | Product planning | Vision + MVP |
| M8 | Architecture | Initial architecture |
| M9 | Repository setup | GitHub-ready structure |
| M10 | Review | Final Unit-1 submission |

## Suggested Agile Backlog

### Epic 1: Identity and Access
- Login
- Role management
- Authorization

### Epic 2: Student Records
- Student registration
- Profile management
- Search

### Epic 3: Courses
- Course management
- Enrollment

### Epic 4: Attendance
- Attendance entry
- Attendance calculation
- Attendance history

### Epic 5: Results
- Marks entry
- Validation
- Result publication

### Epic 6: Reporting
- Academic report
- Export

## Priority

Use MoSCoW prioritization:

- **Must:** Authentication, student registration, records, attendance, reports
- **Should:** Audit log, result workflow
- **Could:** Notifications, advanced dashboards
- **Won't for MVP:** Payments, hostel, library, predictive analytics
